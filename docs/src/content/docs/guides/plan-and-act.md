## Planned content

- What plan mode is for: investigate and propose before changing anything
- `/plan` and `/act`, and Shift+Tab to toggle without losing the draft
- Queueing a mode switch during a running turn (press again to cancel)
- The footer indicator (`[plan]` / `[act]`)
- Exactly what plan mode exposes: built-in `read`, `grep`, `glob`, `read_skill`
- What plan mode disables: edits, shell execution, extension tools, hosted
  web search, and hooks
- Execution-time rejection of unadvertised tool calls
- What still works: session history saving, explicit configuration commands
- Scope: modes apply to the process (including `/new` and `/resume`);
  restarting starts in act mode
- Planning is optional and needs no separate plan file
